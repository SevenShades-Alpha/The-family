# 家庭旅行日记 · 微信小程序云开发 MVP

这是一个使用微信原生小程序 + 微信云开发实现的家庭内部旅行记录项目。包含：微信身份识别、创建/加入家庭、旅行时间线、图文发布、日记详情、评论点赞、城市打卡地图、家庭统计。

## 目录结构

```text
family-travel-diary/
├── project.config.json
├── miniprogram/
│   ├── app.js / app.json / app.wxss
│   ├── utils/                 # 云函数调用、城市坐标表
│   ├── assets/                # 地图标记与默认头像
│   └── pages/                 # login、timeline、publish、detail、map、city、mine
└── cloudfunctions/
    ├── api/                   # 家庭、日记、互动、统计；所有数据访问在这里授权
    └── location/              # 腾讯位置服务地点提示、逆地址解析
```

## 一、准备条件

1. 使用自己的微信小程序 AppID，在微信开发者工具新建原生小程序项目。
2. 在云开发控制台创建一个环境，复制环境 ID。
3. 把 `miniprogram/app.js` 中的 `YOUR_CLOUD_ENV_ID` 替换为真实环境 ID。
4. 首次开发可将 `project.config.json` 的 `appid` 保持为工具生成的实际 AppID；不要把 `touristappid` 用于正式运行。
5. 目前城市标记坐标表放在 `miniprogram/utils/cities.js`，后续可扩展世界城市。

## 二、部署云函数

在微信开发者工具中打开项目，并确认“云开发”已启用：

1. 右键 `cloudfunctions/api` → “创建并部署：云端安装依赖”。
2. 右键 `cloudfunctions/location` → “创建并部署：云端安装依赖”。
3. 云函数使用当前云环境，`wx-server-sdk` 由对应 `package.json` 声明。

## 三、创建数据库集合

在云开发控制台手动创建以下集合（名称必须一致）：

- `users`
- `families`
- `family_members`
- `diaries`
- `diary_images`
- `places`
- `checkins`
- `comments`
- `likes`

### 数据权限（重要）

将这些集合设置为普通小程序客户端不可直接读写、只允许管理端/云函数访问的权限模式。具体可选项以云开发控制台当前界面为准。代码统一通过云函数校验身份和家庭成员资格后再读写数据库；不要为了让前端能读数据而开放集合。

云存储文件权限建议设置为“仅创建者可读写”或控制台提供的等效安全权限：成员上传自己的图片；读取时由 `api` 云函数先验证家庭权限，再生成短时有效的临时 URL，供同家庭成员显示。上传安全策略要以当前环境支持的存储规则为准。

## 四、腾讯位置服务（可选但推荐）

MVP 的选点可直接使用微信原生 `wx.chooseLocation()`；若要在发布页输入关键词搜索地点，则需要腾讯位置服务 WebService Key：

1. 在腾讯位置服务控制台创建 Key，并启用地点关键词提示和逆地址解析接口。
2. 在云开发控制台为 `location` 云函数配置环境变量 `TENCENT_MAP_KEY`。
3. 重新部署 `location` 云函数。不要把 Key 写入小程序前端代码。
4. 在微信小程序后台配置位置相关隐私保护指引，并按实际调用的 `wx.getLocation`、`wx.chooseLocation` 等接口完成所需声明。

如果没有设置 `TENCENT_MAP_KEY`，搜索提示会失败，但“地图选点”和手工填写城市仍可以用于记录。

## 五、运行检查清单

- [ ] `app.js` 的云环境 ID 已替换。
- [ ] 两个云函数已部署。
- [ ] 九个集合已创建并禁止客户端直接读写。
- [ ] 云存储允许当前方案上传图片，图片通过云函数短时 URL 返回。
- [ ] 首次打开能创建家庭；另一微信号输入邀请码能加入。
- [ ] 发布一篇包含城市的日记后，时间线可见且地图城市变为橙色。
- [ ] 不属于该家庭的账号无法从云函数读取家庭日记。
- [ ] 真机测试定位、选择地点、图片上传和隐私授权流程。

## 六、MVP 已知边界

- 时间线一次加载最近 100 条以内的记录；后续可增加分页。
- 地图用预设中国城市中心点 + 标记，不绘制行政区边界；陌生城市如需在地图显示，需提供经纬度。
- 邀请码可手动复制分享；二维码、邀请码过期、踢出成员等管理能力暂缓。
- 目前一名用户只绑定一个家庭，适合简单家庭内部使用。
- 发布日记成功后自动按城市创建家庭足迹；同一城市的“到访次数”按日期做近似去重，并非精确旅行行程次数。
- 点赞和评论可用；没有编辑日记、删除日记、评论删除等管理能力，正式使用前可按需要追加。

## 七、隐私提醒

该项目是“家庭内部使用”的产品设计，但小程序上线仍需遵守微信平台的用户隐私与数据规则。只请求必要权限；不给不属于家庭的成员返回数据；不要把 OpenID、腾讯地图 Key 或长期公开图片地址展示在客户端。家庭成员仍可截屏或转发他们已看到的内容，因此应用层权限无法阻止成员主动泄露内容。
